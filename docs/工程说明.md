# 工程说明

本文说明 EduGraph AI 学习模式在 DSH 里的落地方式、与原方案的对应关系、关键算法与取舍。安装与使用见 [README](../README.md)。

## 1. 与原方案的对应

| 原方案 | 本实现 | 说明 |
|---|---|---|
| 顶部栏「学习模式」开关 | 侧栏入口 + 面板内「返回对话」 | 主面板切换由 `ctx.layout.selectPanel('learning')` / `selectPanel(null)` 完成，等价于一键切换且不新建会话。DSH 在 Windows 上没有顶部栏可插入的 slot（`shell.leading` 仅 macOS），因此用侧栏入口承载开关。 |
| 学习主面板 | root 作用域 keyed slot `main` 的 `learning` key | 与「插件」页同一机制，属于 DSH 原生全局面板，不是浮层。 |
| 学习 preset / 指令 | 20 个原生工具 + 工具描述里的教学策略 | DSH 的 preset 由 profile 配置装配；插件按模型可见的方式暴露能力更直接：模型在任意会话中都能读大纲、建计划、出题、判分，也能导入外部课程包。 |
| MCP 服务 | `ctx.tools.register(definition)` | 同进程注册，参数 schema 直接进入系统提示词；返回 `entity_id/version/updated_at` 的约定保留。 |
| FastAPI + PostgreSQL + Redis | `lib/api.js`（node:http）+ `lib/store.js`（JSON） | 单用户本地应用的最优成本；接口形状与原方案一致（`/api/courses` 等对应 `/plugins/edugraph-learning/api/courses`）。 |
| Docling / MinerU | `lib/parse/*` | PDF 用 pdfjs 取字与字号；OOXML 用内置 zlib 手写解压，零第三方依赖（除 pdfjs）。 |
| React Flow | 自绘 SVG 分层图 | 章节为列、概念为节点、依赖为边；无额外运行时依赖，颜色直接映射掌握度。 |
| Py-FSRS | `lib/fsrs.js` | FSRS-5 公式与默认权重，纯函数实现，可单测。 |

## 2. 数据模型

课程知识（可重建）与个人状态（不可重建）分开：

```
courses/<id>/blocks.json   文档 → 页 → 块（写一次）
courses/<id>/meta.json     course / chapters / concepts / relations
                           profile / plan / questions / attempts / events / reviews
```

概念是知识侧的唯一锚点，个人侧的 `attempts`、`reviews` 都通过 `conceptId` 引用它。重新分析资料时：

1. 章节按标题匹配旧 id（同标题同层级复用）；
2. 概念按归一化名称复用旧 id；
3. 人工补充的概念（`manual: true`）不被自动分析覆盖；
4. 计划按「类型 + 概念集合」继承完成状态。

因此删资料、加资料、改目标都不会把学习记录清零。

## 3. 解析

| 格式 | 方法 | 要点 |
|---|---|---|
| PDF | pdfjs legacy build | 按 y 坐标聚行、按 x 排序拼接（中文不插空格）；字号众数判断标题层级；重复 ≥50% 页面的短行视为页眉页脚丢弃；CID 字体带 cMap |
| DOCX | 手写 OOXML | `w:pStyle` Heading1-6 → level；`w:p` → 段落；`w:tbl` → 表格行 |
| PPTX | 手写 OOXML | 每张 slide 一页，标题占位符 → heading |
| XLSX | 手写 OOXML | 每个 sheet 一页，每行一条 table 块 |
| MD/TXT | 语法识别 | 标题 / 代码块 / 列表 / 表格；按 ~1800 字切虚拟页 |
| 图片 | 登记 | 记文件名占位，交给模型视觉工具读图 |

落库前统一清洗：折叠「二极管导通二极管导通」这类整段重复（伪粗体/阴影），压缩空白，丢弃空块。

## 4. 结构分析（`analyze.js`）

1. **标题识别**：解析器给的 heading 优先；否则字号 ≥ 正文 1.22 倍按比例映射 1-3 级；再否则用编号模式（第X章 / 一、/ 1.2）。公式行（含 `=`、数学斜体、非中日韩占比过低）一律不算标题。
2. **章节树**：标题开节，吸收其下内容；过短的子节合并进父节；无标题资料按字符量切「第 N 部分」。
3. **概念**：
   - 标题即概念（置信 0.82）；
   - 定义句式（`X是指/称为/定义为…`，置信 0.74）；
   - 术语频次（中文 2-8 字窗口 + 英文词，极大性过滤：`极管` 让位给 `二极管`；两字词要求出现 ≥8 次；通用词与句段黑名单）；
   - 英文缩写（NPV/PNP/VCC）。
   每个概念保留 `sourceRefs`（文档/页/块/摘录）。
4. **定义选择**：从句子里挑最像定义的——定义句式 +3、句首出现 +2，例题/如图/求解 −2.5，公式句 −2.5，过短/过长降权。
5. **关系**：`prerequisite`（A 出现在 B 的定义里且章节更早，权重 = 提及次数）、`related`（相邻章节共现）。每概念最多 4 条前置、6 条相关。

## 5. 计划（`plan.js`）

- 概念按章节序 + 首次出现页排序，切成 1-3 个概念的教学单元；
- 单元 → 讲解（12 分钟）+ 练习（8 分钟）；
- 按每日可用分钟装天；考试日期决定总天数，无考试日期默认 14 天；
- 每章 ≥2 个概念时插阶段测验；
- 每个单元在 +1/+3/+7 天插复习任务；
- 结束插总复习；
- 重新生成时按 `type:概念集合` 继承 `done/skipped`。

## 6. 题目与判分

| 题型 | 生成方式 | 判分 |
|---|---|---|
| choice | 定义做正确项，同章其他概念定义做干扰项，选项顺序由概念 id 哈希决定 | 选项下标严格相等 |
| choice-reverse | 定义做题干，概念名做选项 | 同上 |
| cloze | 原文句挖掉术语 | 归一化包含或 Dice 相似度 ≥0.8 |
| judge | 正确定义 / 换成别的概念的定义 | 0/1 |
| short | 「用自己的话解释 X」 | 关键点覆盖率 0.72 + 术语命中 0.18 + 篇幅 0.1 |

分数映射 FSRS 评分：≥0.85 → 4，≥0.62 → 3，≥0.35 → 2，否则 1。掌握度 = 答题成绩指数加权（衰减 0.75）× 0.75 + 复习稳定性 × 0.25。

## 7. 存储与一致性

- 写：`tmp → rename`，同一课程的读改写走 `KeyedLock`，避免并发覆盖；
- 读：内存缓存 + 索引文件，列表页不加载整门课；
- 损坏：JSON 解析失败时把原文件改名为 `.corrupt-<ts>` 并报错，不静默丢数据；
- 检索索引：按 `meta.updatedAt` 懒构建，课程变更即失效。

## 8. 界面

- 面板注册在 `main` keyed slot，侧栏注册 `sidebar.panellist`，图标与文案随主题；
- 颜色全部取 `--dsw-*` 主题令牌，亮/暗自动适配；顶部内边距读 `--dsh-frame-top-clearance`，不与窗口 chrome 冲突；
- 状态：服务端 `state.json` 持久化「当前课程 / 当前页」，刷新与重开都恢复；到期复习数做侧栏角标；
- 图谱为自绘 SVG：章节分列，节点半径随度数，颜色随掌握度，实线箭头 = 前置依赖，支持拖拽平移与缩放。

## 8.1 图示（v1.1）

电路图有两种：位图与矢量。位图直接从 Office 包里抽；矢量（PDF 里画出来的三极管、波形）文字层里没有，只能**渲染页面**。

- 渲染：`pdfjs-dist` 解析 + `canvas`(node-canvas) 绘制，1.6 倍分辨率，白底，输出 PNG；
- 触发：按需——用户点「看这一页的图」或 Agent 调 `get_page_image` 时才渲染；
- 缓存：`courses/<id>/figures/<doc>-p<page>.png`，二次访问直接读盘；
- 原始文件：上传时留一份到 `courses/<id>/documents/`，否则事后无法渲染；
- 降级：`canvas` 没装时返回可读错误（提示 npm install canvas），其它功能不受影响；
- 缓存（v1.1.1）：同一份 PDF 只解析一次，翻页复用；最多缓存 3 份文件（按最近使用淘汰）；
- 查看器：图与原文页码联动，← → 翻页；Word/PPT 走内嵌图片画廊；
- AI 看图：工具返回本地路径，模型用 `read_image` 读取，视觉理解交给模型，不内置 OCR/CV。

## 8.2 知识图谱（v1.1）

- 布局：自写受力模拟（斥力 + 依赖弹簧 + 章节重心），300 次迭代后归一化到画布；
- 小图（≤40 点）：常驻标签、章节色块、悬停高亮邻居、点击聚焦；
- 大图（>40 点）：进入时自动聚焦到知识点最多的那一章，按子图重新布局；章节下拉 + 芯片切换；「回到章节总览」一键返回；
- 视觉：章节配色（7 色循环）、命题边按来源章节着色、箭头灰色、节点按熟练度渐变、入场动画（定位与动画分层，避免 CSS transform 覆盖 translate）。

## 8.3 文案（v1.1）

界面与工具描述统一改成人话：不写「置信度/FSRS/掌握度向量」，写「熟练度/下次复习/哪里还生」；按钮写清动作（「排计划」「看这一页的图」「回到章节总览」）；概览页永远只给一个「现在做这个」。

## 8.4 界面与自适应（v1.2）

- **三栏骨架**：左侧课程导航 / 中间学习内容 / 右侧 AI 导师。导航按「学习 / 练习」分组，课程卡内含切换课程、进度环和待复习角标；
- **视觉**：靛蓝主色 + 薄荷辅色，统一的卡片圆角与层级阴影，课程库首屏用渐变 Hero 加知识点装饰图；颜色仍以 `--dsw-*` 主题令牌为底，亮/暗自动适配；
- **自适应**：面板根节点设 `container-type: inline-size`，按 DSH 主区域的实际宽度（不是窗口宽度）切换：
  - 宽度足够：左栏 252px + 内容 + 右栏 `clamp(348px, 30cqi, 430px)`；
  - 面板 ≤1360px 且右栏打开：左栏收成 76px 图标条，把空间让给内容；右栏收起时左栏保持 236px；
  - 面板 ≤1040px：右栏改成右侧浮层，不再占列；
  - 面板 ≤760px：左栏变顶部横向导航；
  - 正文 `.eg-main-inner` 同样建立容器上下文，`.eg-split`、Hero、统计卡按内容宽度重排；
- **课程库不是空态**：进入课程库仍保留当前课程上下文，左栏导航不消失；只有真的没有课程时才显示「从一门课开始」。

## 8.5 课程项目 + 独立导师会话（v1.5.0）

- **课程项目**：宿主 `lib/project.js` 的 `ensureProject` 在 `<当前工作区>/EduGraph/EduGraph - <课程名>` 建目录，把课程 `meta.documents` 对应的原始文件复制到 `materials/`，写 `project.json` 和 `README.md`；项目路径存进课程 meta 的 `project.path`。同名课程用课程 id 后缀避让；文件名做 Windows/POSIX 安全化；重名资料自动加序号。
- **工作区注册**：客户端先调 `POST /courses/:id/project {basePath}`，再用 `workspaces.create({path: project.path})` 把项目文件夹注册成新的 DSH 工作区；如果工作区列表里已有同路径，直接复用。插件客户端 `inject` 必须包含 `workspaces` 和 `uiWorkspace`，否则 Cordis 会报“cannot get property without inject”。
- **资料副本**：项目是插件存储的可见副本，不是唯一源；这样解析缓存、页面渲染和出题不受项目目录移动影响。项目弹窗的「重新同步资料」会再次复制当前资料。
- **导师会话**：`src/client/tutor-session.ts` 的 `ensureTutor(courseId, projectWorkspaceId)` 调用 `uiWorkspace.openWorkspace(projectWorkspaceId)` 在项目工作区创建/复用一个空白会话并设为 mainView，随后立刻 `layout.selectPanel('learning')` 留在学习面板；面板 owner 的原生 `conversation.content` 渲染的就是这条导师会话。会话 id 按课程存在 localStorage（v2 key，旧的默认工作区导师不迁移），进入学习前的主会话也存着，「返回对话」用 `openSession(previous)` 切回。
- **项目入口**：课程顶部「项目」打开 `ProjectModal`：项目路径、资料清单、打开项目（`uiWorkspace.openWorkspace`）、打开导师会话（ensureTutor + `openSession`）、复制项目路径、重新同步。没有课程时不显示。
- **上下文提问**：讲解/错题/图谱/概览通过 `src/client/tutor.ts` 事件总线把 prompt 交给面板；面板先确保项目/导师，再调用 `ctx.sessions.scope(tutorId).get('conversation').send(text)` 发到导师会话，不经过主会话，也不 postMessage 过 iframe。
- **能力保留**：导师会话的消息、composer、模型选择、工具、审批、队列都是 DSH 原生；模型选择是这条会话自己的，和主会话分开。插件工具默认读取界面里打开的课程。
- **空态/加载/错误**：第一次建项目/导师会显示准备态，失败可重试；没有课程不渲染右侧，避免把主对话当成导师。
- **兜底 iframe**：没有 `renderFactorySlot` 的嵌入环境才用同源 iframe。宿主 `/chat-info` 给出 HTTP origin，`/chat-frame` 302 到带启动 token 的 HTTP 地址；父页面只接受该 iframe 的 source/已知 origin 的消息。
- **桌面端限制**：`dsh-app://app/` 主页面直接嵌自定义协议 iframe 拿不到启动注入；跨 origin 的 token 重定向又会被第三方 cookie 拦截（实测 iframe 落在 `dsh web authentication required`）。因此主路径必须是原生 slot，不要回退到 iframe。
- **已知取舍**：项目会出现在 DSH 工作区列表里；每门课一个，列表会变长。项目资料是副本，会占额外空间。导师会话短暂成为 mainView，返回时恢复；主对话内容不丢。

## 8.6 外部 AI 课程包（v1.3）

- **目标**：ChatGPT / Claude / Gemini 不直接接触插件文件；导出 `edugraph-course-pack v1` JSON 和提示词，外部模型改完后把 JSON 粘回，由服务端校验合并。
- **入口**：课程顶栏「AI 内容」→「复制给 AI / 导入 AI 结果」；文件只走文本，不需要 API key，桌面端和网页版都能用。
- **服务端**：`lib/pack.js` 负责导出、字段/长度/题型/答案校验、概念名归一化、章节/概念/题目/关系合并；`service.exportPack/previewPack/importPack` 暴露给 API 和工具；`GET /courses/:id/pack`、`POST /courses/:id/pack/preview`、`POST /courses/:id/pack`。
- **合并规则**：只追加/补空，同名概念合并；已有定义默认不覆盖（可勾选）；重复题目跳过；题目 `origin='external-ai'`，`createQuiz` 优先使用导入题目，再用规则题补齐；概念引用/选项下标/判断题答案不合法就跳过并返回 warning。
- **计划**：课程包里的 `plan` 只作外部模型上下文，导入不改现有计划，避免覆盖已完成任务；需要时去计划页重排。
- **工具**：`export_course_pack`、`import_course_pack`，DSH 里的其他模型/子代理可以直接调用，不必复制粘贴。
